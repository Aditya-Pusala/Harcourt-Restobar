# Harcourt Restobar

Pizza-and-wine restobar website for Harcourt, Victoria, Australia.

## Status

**Phase 1 - Frontend only (in progress).**

- Frontend pages completed: 0/25
- Backend-connected pages: 0/25
- Acceptance tests passed: 0/18

All data in Phase 1 is clearly labelled sample/mock data. Any browser storage used is local demo persistence only, not a shared production database. No payments, emails, live orders or tracking are processed.

See PAGE_INVENTORY.md and PROJECT_CHECKLIST.md for progress.

## Stack

Next.js (App Router), TypeScript, Tailwind CSS, Framer Motion. Later phases: Supabase, Stripe.
